# 🧠 AI Exploration Log – Dictionary App & Image Generation with OpenAI

This repository captures my learning and coding journey on **July 4, 2025**, where I explored API integration, dictionary app development, and AI-powered image generation using OpenAI’s tools. It includes hands-on code in Jupyter Notebook and reflective insights.

---

## 🚀 Project Highlights

### 1. 🗂️ **Dictionary App (Python)**
A terminal-based Python app that:
- Takes a word as input
- Fetches definitions from a free dictionary API
- Parses and displays the first definition, example usage, and part of speech
- [Optional] Planned extensions include pronunciation audio and GUI integration

### 2. 🎨 **AI Image Generation**
- Explored OpenAI’s image generation APIs
- Attempted to use `gpt-image-1` model but hit verification requirements
- Successfully switched to `dall-e-3` model for image generation
- Implemented code in Python to send a prompt and receive AI-generated images
- Learned the key differences between image generation models and how to handle deprecated functions in updated APIs

---

## 📚 Key Learnings

- Working with **public APIs** in Python (GET requests, JSON parsing)
- Understanding **nested dictionaries** and error handling in JSON structures
- Using **OpenAI's Python client** to interact with image generation models
- Differences between **GPT-4.1, GPT-4o, GPT-4.5**, and **reasoning models**
- The role of **vector stores** and their integration with OpenAI models
- Overview of **Response API**, **MCP (Model Context Protocol)**, and OpenAI best practices
